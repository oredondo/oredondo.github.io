# Action Verbs for Platform, Cloud & AI Engineering

Use strong, specific active verbs to begin every bullet point. Never start with passive expressions like *"Responsible for"*, *"Worked on"*, *"Assisted in"*, or *"Helped with"*.

---

## 1. Architecture, Conception & System Design

| English | Español | Context / Usage |
| :--- | :--- | :--- |
| **Architected** | *Diseñé / Concebí la arquitectura* | Designing multi-component distributed systems from scratch. |
| **Conceived** | *Concebí* | Ideating an original tool or platform engine (e.g., Blueprint, Orion). |
| **Engineered** | *Construí / Desarrollé* | Rigorous software engineering of complex backend pipelines. |
| **Pioneered** | *Pionero en concebir* | Introducing novel patterns (e.g., LangGraph ReAct operational agents). |
| **Spearheaded** | *Lideré estratégicamente* | Leading major technical initiatives (e.g., Jenkins to HA Dispatcher migration). |
| **Standardized** | *Estandaricé* | Establishing organization-wide deployment or CI/CD frameworks. |

## 2. Infrastructure, Orchestration & IaC

| English | Español | Context / Usage |
| :--- | :--- | :--- |
| **Decoupled** | *Desacoplé* | Separating variable management from playbook execution. |
| **Abstracted** | *Abstraje* | Hiding multi-cloud complexity behind a unified driver interface. |
| **Reconciled** | *Reconcilié* | Aligning live cloud infrastructure with declarative state. |
| **Automated** | *Automaticé* | Replacing manual ticketing with self-service programmatic execution. |
| **Orchestrated** | *Orquesté* | Coordinating multi-step parallel DAG provisioning. |
| **Provisioned** | *Aprovisioné* | Creating and bootstrapping compute, network, and storage assets. |

---

## 3. Scale, Performance & Reliability

| English | Español | Context / Usage |
| :--- | :--- | :--- |
| **Slashed** | *Reduje drásticamente* | Cutting MTTR or build latency (e.g., from hours to seconds). |
| **Eliminated** | *Eliminé* | Removing single points of failure (SPOFs) or commercial license lock-in. |
| **Optimized** | *Optimicé* | Tuning high-volume query throughput or memory footprint. |
| **Restored** | *Restauré con cero downtime* | Recovering broken interoperability (e.g., F5 / OpenStack API bridge). |
| **Governed** | *Goberné* | Enforcing compliance, RBAC, and inventory state across 30,000+ assets. |
| **Scaled** | *Escalé* | Supporting growth to 40,000+ daily ops without performance degradation. |

## 4. Applied AI & Multi-Agent Systems

| English | Español | Context / Usage |
| :--- | :--- | :--- |
| **Constrained** | *Acoté bajo guardarraíles* | Enforcing deterministic Pydantic schemas on LLM outputs. |
| **Synthesized** | *Sinteticé* | Aggregating logs, runbooks, and diffs into actionable root-cause reports. |
| **Correlated** | *Correlacioné* | Connecting execution failure traces with repository commits. |
| **Isolated** | *Aislé* | Restricting AI agent access through read-only Model Context Protocol (MCP) tools. |
| **Ingested** | *Ingerí* | Feeding unstructured multimodal streams into processing graphs. |

## 5. Technical Leadership & Global Impact

| English | Español | Context / Usage |
| :--- | :--- | :--- |
| **Led** | *Lideré* | Guiding cross-functional teams and international integrations. |
| **Onboarded** | *Realicé el onboarding técnico* | Integrating international engineering hubs (Mexico, Turkey). |

| **Owned** | *Asumí la responsabilidad* | Carrying on-call incident response and platform evolution end-to-end. |
